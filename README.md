# JobTrack API

JobTrack API is a backend application for managing job applications.

The project is being developed as a practical way to learn Java, Spring Boot, databases, testing, security, Docker, and Git.

## Planned Features

* Add and manage job applications
* Change application status
* Save company and position information
* Schedule interviews
* Search and filter applications
* View application statistics
* User registration and authentication

## Application Statuses

* `SAVED`
* `APPLIED`
* `INTERVIEW`
* `OFFER`
* `REJECTED`

## Technologies

* Java 21
* Spring Boot
* Maven

The following technologies will be added during development:

* PostgreSQL
* Spring Data JPA
* Hibernate
* Spring Security
* JUnit
* Mockito
* Docker
* Swagger
